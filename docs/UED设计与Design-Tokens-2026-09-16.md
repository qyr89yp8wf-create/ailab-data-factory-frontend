# 数据生成工具：UED 设计与 Design Tokens

版本：1.0（待实施）  
日期：2026-09-16  
范围：首页、数据中心、数据集与版本、质检报告、三类数据任务、模板、API 配置。  
依据：[UED审查与优化建议](./UED审查与优化建议-2026-09-16.md)。本文件的尺寸、颜色和交互规则为建议目标，不是对当前样式的测量结果，也不表示已实现。

## 1. 设计目标

产品应呈现为安静、清楚、可靠的数据工作台。用户每一屏都能回答：我在处理什么对象、当前结果是什么、下一步做什么。

### 1.1 五项约束

1. **一个页面一个主要任务。** 配置时突出字段，查问题时突出证据。
2. **一条主阅读线。** 辅助信息不能与主体争宽度、抢颜色、制造第二条长滚动区。
3. **容器有明确语义。** 页面承载对象，区块组织内容，侧栏查看短细节，弹窗处理短决策。
4. **颜色表达状态与操作。** 普通说明不使用大色块；未发生的成功不使用绿色成功态。
5. **复杂能力渐进展开。** 必填项始终可见，高级参数、计分口径和原始 JSON 按需查看。

### 1.2 需保留的业务语义

- 数据集、版本、报告的关联必须可追溯；视觉扁平化不改变这些实体关系。
- 报告的通过、不通过、无法判定、不适用、未抽中、未执行保持独立。
- 隐私处置不能因为提示降权而变成可选；保留必要行动与处理方式。
- 模板冻结、输出版本、样本级结果以及自动复检的业务逻辑保持清晰可查。
- 模拟产物必须有就近、稳定的“模拟数据”标识，不能让用户误认成真实模型检测或真实生成结果。

## 2. 信息架构

```text
工作台
├─ 数据中心
│  ├─ 上传数据
│  └─ 数据集详情（主页面）
│     ├─ 版本列表 / 当前版本选择
│     ├─ 概览
│     ├─ 数据预览
│     ├─ 质检报告 → 规则结果（页内钻取）→ 样本证据（单侧栏）
│     └─ 来源与去向
├─ 任务中心
│  ├─ 文档图像 / 对话文本 / 时序数据
│  ├─ 新建任务：合成 / 质检 / 增强 / 定向扩增
│  └─ 任务详情（主页面）
│     ├─ 概览 / 结果 / 异常样本 / 日志 / 配置
│     └─ 关联数据版本与报告
├─ 模板中心
│  ├─ 模板详情（只读）
│  └─ 模板编辑工作区 / 试运行结果
└─ 模型服务（原 API Keys，可保留 API Keys 为副标题）
```

导航状态应可定位到对象与页签。浏览器返回与页面返回语义一致；列表筛选、页码和滚动位置可恢复。这里定义行为要求，不限定具体路由框架。

## 3. 全局布局与响应规则

### 3.1 工作台框架

- 默认明亮中性色导航；品牌蓝用于选中项与主操作。是否保留深色侧栏可由品牌要求决定，但不能逐页混用两套。
- 左导航 216px，折叠 64px；导航项 40px 高、间距 4px。
- 全局面包屑栏 48px；页面操作栏 56px。两者同时固定时内容起点为 104px。
- 页面内边距 24px；最大内容宽 1440px，超宽居中。
- 主页面只设一个纵向滚动容器；表格可使用局部横向滚动，但不能让主操作列或关键原因默认离屏。

### 3.2 宽度与降级

| 可用视口宽度 | 任务配置 | 列表/报告 | 编辑工作区 |
|---|---|---|---|
| ≥1440px | 主表单 800～960px；可选摘要栏 280px，间隔24px | 默认关键列完整 | 可使用字段240 / 画布弹性 / 属性280三栏 |
| 1200～1439px | 单列，摘要置于输入区；表单最大960px | 收起低频列，保留名称、状态、关键结果、操作 | 属性面板按需打开，避免同时挤压画布 |
| 768～1199px | 侧栏折叠；单列字段或足够宽的两列 | 可选择显示列；表格局部横滚 | 单面板切换，画布保留最大可用空间 |
| <768px 或高倍缩放 | 单列；操作栏可换行且不遮正文 | 优先对象摘要与详情入口 | 支持查看与基本编辑，复杂画布需专门布局 |

响应式设计依据实际可用宽度，不能只凭屏幕总宽决定四列布局。普通字段最小建议宽 240px；小数字字段可更窄，但标签必须完整可读。

## 4. 数据中心与版本详情

### 4.1 列表

```text
数据中心                                           [上传数据]
[全部 / 文档图像 / 对话文本 / 时序数据]
[搜索名称或ID────────] [来源▼] [业务类型▼] [重置]
名称 / 短ID        类型     最新版本结果    样本数    更新时间     更多
物流运单图像数据集  文档图像  已完成质检     100       09-15 15:46  ⋯
```

- 名称为主入口；不再同时放名称链接和“详情”。
- “删除”移入更多菜单底部，与普通操作分隔。
- ID 默认显示前后片段，完整值通过展开/悬浮/复制获得；键盘同样能访问完整值。
- 区分数据集总样本与当前版本样本，不能统称“样本数”造成误解。
- 空库：“还没有数据集”+“上传数据”；无搜索结果：“没有匹配的数据集”+“清空筛选”。

### 4.2 数据集详情线框

```text
数据中心 / 物流运单图像数据集
物流运单图像数据集                     [新建任务▼] [更多]
文档图像 · 国内运单     数据集ID… [复制]
[当前版本：增强 · 09-15 15:46 · F345… ▼]   100张 · 已完成
概览 | 数据预览 | 质检报告 | 来源与去向
────────────────────────────────────────────────────
当前页签的完整内容
```

- 数据集元数据默认为简洁键值，不套多张边框表。
- 版本列表在独立区域展示，切换版本更新同一页面，不打开第二个抽屉。
- 数据集描述可就地编辑或使用一个短弹窗；保存反馈贴近字段。
- 来源任务/模板是明确链接；跳转前不保留旧抽屉遮罩。

### 4.3 数据预览

- 文档：画布与标注联动；选中字段只高亮相关框，默认不把所有文字标签铺满画布。支持适应画布、缩放、上/下一张。
- 对话：消息时间线区分角色、工具调用与结果；原始 JSON 为次级页签。
- 时序：趋势图配合字段选择和异常区间；表格/JSON为次级视图，标注采样间隔与单位。
- 样本顶部固定展示当前位置、短ID、过滤条件和上/下一条；切换时清理上一样本的证据选中态。
- 不将示意图包装成生成成品；模拟来源标签放在预览标题附近。

## 5. 质检报告与异常样本

### 5.1 报告页

```text
质检报告   [报告时间与范围▼]                         [导出▼]
已完成 · 抽检95/100张 · 模拟数据
需处理：6项规则存在不通过结果                [查看不通过结果]
整体分数 94.7   有效判定覆盖率 100%     隐私命中 5条结果
计算方式 ⓘ
[规则搜索────────] [规则分类▼] [只看有问题]
规则名称           不通过    通过率     未判定/未执行摘要    查看
...
```

- 第一层展示检查范围、执行状态和待处理结果。分数不能掩盖未执行或隐私问题。
- 聚合规则失败次数不能冒充去重样本数；界面标签写清计数单位。
- 默认表格：规则名称、不通过数、通过率、其他状态摘要、详情；完整统计列可展开。
- 非零且可查看的数量才是链接；零值为文本。
- 标签分布有数据时显示；没有数据时一行解释“本报告未记录标签分布”，不放高空白大卡。
- 抽检报告保持“仅代表抽检范围”这一必要限定，靠状态标签/摘要表达，不隐藏进深层帮助。

### 5.2 规则钻取与样本侧栏

- 点击规则：主页面切换为规则结果，面包屑可回报告。
- 顶部：规则名称、通过条件简述、各结果状态筛选。
- 表格：样本短ID、检查位置、失败原因摘要、证据入口。优先显示失败原因。
- 点击样本：打开 720px 侧栏；可用宽度不足时占满内容区。仅一个遮罩。
- 侧栏内：样本预览、问题位置、判定依据、原始数据折叠；上/下一条延续当前筛选。
- 单条证据不显示分页；多条证据用列表。关闭后焦点回到原行。

### 5.3 日志与配置

- 日志默认列：时间、阶段、状态、说明；提供级别过滤、搜索、复制/导出。
- 技术堆栈按需展开，正文不直接放整块运行JSON。
- 配置默认显示输入、模板版本、策略、模型、输出；原始快照独立页签。
- 空报告分别表达“未开始”“处理中”“生成失败”“无适用规则”，并提供相应下一步。

## 6. 任务创建：统一骨架

### 6.1 表单顺序

```text
‹ 任务列表    新建数据增强任务             [保存草稿] [提交任务]
────────────────────紧凑固定栏───────────────────────
任务信息
任务名称 [────────────────────────────────────────]
任务描述 [可选────────────────────────────────────]

输入数据
数据集 [─────────────────────────────────────────▼]
版本   [─────────────────────────────────────────▼]
报告   [最新有效报告──────────────────────────────▼]
100张 · 抽检95张 · 5条隐私命中结果     查看完整报告 ↗

增强策略
目标样本数 [100]       强度 [中等▼]
语义增强 ...
图像增强 ...
隐私处理 [部分掩码▼]（系统必需）
高级模型参数 ▸

输出
写入：物流运单图像数据集的新版本
版本描述 [────────────────────────────────────────]
完成后生成1个新版本，包含增强样本与复检结果。
```

### 6.2 公共交互

- 主操作只有“提交任务”；“保存草稿”为次按钮。反馈明确保存时间和恢复入口。
- 任务名称、描述不吸顶。配置区最多“区块→字段组”两层容器。
- 选定输入前不展示两块巨大空状态；选定后就地出现相关配置，不突然创建第二条长阅读线。
- 切换数据集后，版本/报告保持兼容才保留；不兼容则清空并明确提示需要重新选择。不能静默沿用旧报告。
- 只读输出位置使用普通文本+链接，不画禁用输入框。
- 开关仅用于启用能力；“查看高级参数”使用折叠组件，不把展示开关与业务开关混为一谈。
- 可选项关闭后不参与校验；重新打开可恢复当前会话输入。删除自定义组只影响未保存草稿时可就地撤销。
- 提交错误：顶部简述错误数量，聚焦首个字段；字段旁显示原因与改法。滚动定位留出固定栏高度。
- 未保存离开：仅有实际修改时提示保存草稿/放弃/继续编辑；没有修改不打扰。

### 6.3 四类任务差异

| 任务 | 主配置 | 放入高级/独立详情 |
|---|---|---|
| 合成 | 模板、规模、模态规格、采样分配、输出 | 模板完整规则、模型JSON、完整指令 |
| 质检 | 输入版本、全量/抽检、抽检数量与范围、模型 | 完整规则表、计分口径；输出报告位置用摘要 |
| 增强 | 输入报告、目标规模、增强方法、必要隐私处理、输出 | 自定义Prompt、模型JSON、完整报告 |
| 定向扩增 | 输入报告、目标选择、每项目标、上限、输出 | 自定义目标组、独立模型参数、原始标签分布 |

### 6.4 三模态差异

- **文档图像**：语义、图像、背景为并列方法组；选择后展开其方法。单个预置规则先显示名称和一句作用，完整 Prompt 按需打开。必要时展示小幅预览示意，不把长 Prompt 塞入窄表格。
- **对话文本**：事件采样按维度分组，组标题显示当前合计。条件性维度明确适用范围；整数分配展示最终合计与舍入处理结果。语义增强和隐私处理分开，保留跨轮一致性要求。
- **时序数据**：事件语义与数值参数分成两组；步数、间隔旁展示推导出的窗口时长并注明计算口径。不同物理量显示单位；不适用GPS的场景不默认强调GPS方法。

### 6.5 定向扩增专用布局

- 目标表只保留“选择 / 目标 / 当前问题或覆盖 / 计划新增数”。建议数作为输入旁次级值，不重复一整列。
- 选中目标才启用数量；底部实时显示已选目标、计划合计、最大新增数。
- 超限时说明“计划 X，超过上限 Y”，提供调小数量或修改上限的路径，不仅变红。
- 自定义组：名称与数量一行；目标组合一整行；指令一整行；模型与高级参数在其后。
- 多组收起后显示摘要，如“稀缺标签补齐 · 20条 · Qwen3-14B”，不堆叠完整长表单。

## 7. 模板中心与编辑工作区

### 7.1 查看与编辑分离

- 详情使用可读文本、列表和预览，不能整屏灰色禁用控件。
- 所有“查看详情”“展开规则”“复制”“切换预览”在只读模式仍然可用。
- 草稿显示“编辑模板”；已发布显示“复制为草稿”。发布与试运行状态分别显示，不用相同绿色暗示全部完成。
- 详情默认回到概览或明确恢复上次页签；不能因另一个模板的步骤状态而落到不相关步骤。

### 7.2 对话/时序模板

- 建模阶段可保留五步，但导航用短标题；长解释放对应章节首行，不在每个步骤下重复。
- 主标题、操作、步骤导航合计应尽量控制在正文前 160px 内（不含全局面包屑），让首屏出现真正的配置内容。
- 生成空间中维度、知识卡、工具、字段分别管理，列表展示摘要，展开一项查看详细配置。
- 规则表按分类折叠，提供搜索和启用状态筛选；规则实现名、研发优先级、原始依据进入技术详情。
- 指令预览保留两阶段页签；默认展示输入摘要，完整Prompt/JSON可查看复制。
- 试运行结果优先展示样本、执行结果、异常；原始请求在折叠详情中。试运行未执行时不画空结果表。

### 7.3 文档模板画布

```text
模板名称 · 草稿                [保存草稿] [试运行] [发布]
步骤/页签：基础信息 | 字段与版面 | 规则 | 试运行结果
字段列表 240px       画布（弹性，居中适应）       属性 280px
搜索字段             [缩放- 100% +][适应]       选中字段名称
固定 / 动态          仅突出选中项               示例/类型/规则
中文名称优先         同步定位字段               高级配置 ▸
```

- 普通页面滚动不能把画布卷走；字段列表和属性面板可独立滚动，这属于专业编辑器的明确例外。
- 三栏空间不足时，属性改为切换面板；不把画布压成缩略图。
- 单击字段同步定位画布；画布选中同步定位列表；提供清除选中与恢复适应。
- 低置信度、待校准项明确分组；选中态颜色与质检失败颜色分离。

## 8. 上传与模型服务

- 上传：类型→文件→保存位置→模板绑定，主体同一阅读线；文件限制一行简述，协议细节折叠。文件卡展示进度、错误、重试和移除。
- 上传完成前“发布”不可执行，但应在按钮附近说明缺少的步骤；不依赖用户悬浮禁用按钮。
- API添加：服务商、名称、地址、密钥、模型、描述；只保留一条必要协议帮助，去掉无行动意义的绿色成功块。
- 密钥保持掩码；完整密钥仅在业务确实允许时展示。示例配置明确“未验证/模拟”，不要暗示已经连通。
- 删除弹窗写明对象和影响；不使用含糊“确定吗”。本规范不替代真实权限与服务端安全设计。

## 9. Design Tokens

### 9.1 分层与命名

三层：基础值 `ref.*` → 语义 `sys.*` → 组件 `comp.*`。组件引用语义 token，禁止各页面另写“浅蓝提示卡”“深灰说明框”。下列 CSS 变量为建议的可交付值；工程中可映射到现有 Ant Design 主题与业务组件。

### 9.2 颜色

| sys.color.canvas | #F7F8FA | 页面底色 |
| sys.color.surface | #FFFFFF | 主内容、弹层 |
| sys.color.surfaceSubtle | #F3F5F7 | 表头、只读分组底色 |

| 组件 | 默认 | 交互/异常 |

## 12. 验收标准

### 12.1 设计验收

- 1280×720 下任务配置无字段遮挡、无主表单横滚，主操作可达。
- 数据集→版本→报告→样本路径最多一个侧栏、一个遮罩。
- 首屏有主要内容；模板页不能只有标题、步骤条、解释卡。
- 普通输入/输出说明无大型彩色Alert；真实风险信息仍明确。
- 默认报告可直接找到检查范围、失败原因入口；无需横滚寻找核心结果。
- 查看模式可阅读、复制、展开，不呈现一整页禁用灰框。
- 所有已知故障回归通过，尤其对话规则展开空白页。

### 12.2 交互验收

- Tab 顺序符合阅读顺序；弹层关闭后焦点回原入口。
- 保存草稿后恢复保持字段与条件组；未保存离开有准确提示。
- 输入切换后无陈旧版本/报告残留；关闭的可选组不阻止提交。
- 无结果、未执行、失败、不适用各自文案与操作匹配。
- 浏览器返回保留列表上下文；导出、删除、发布有明确结果与失败反馈。
- 模拟与真实结果区分清楚；所有计数单位与分母可追溯。

### 12.3 交付与回归

先实现数据集报告路径和一种任务表单作为基准，再推广至三模态。每批保留改前/改后同视口截图，复走审查文档对应路径。视觉稿、tokens和业务状态都通过后再扩展，避免分别给每一页打补丁。

本文件提供布局、交互、文案、tokens和验收目标；高保真视觉稿与全部控件状态截图尚未制作。前端实施后仍需进行真实用户任务测试，而不是只以截图更整齐作为完成标准。


## 13. 二轮用户验收更新（2026-09-16，优先于前文冲突条款）

### 13.1 提示信息

普通操作说明必须是灰色小字，**无背景、无左边框、无状态图标**。不能用“无色 Alert”替代这一要求。短说明直接跟随字段；复杂计算口径放标题旁 info icon，可键盘聚焦，hover/focus可读。当前无法继续的操作错误可用红色反馈；提示错误必须给出解决动作，不能将说明包装成成功/风险信息。

| help.color | #667085 | 普通操作说明 |
| help.fontSize / lineHeight | 12px / 20px | 说明字级 |
| help.background / border / icon | transparent / none / none | 禁止装饰强调 |
| help.gap | 8px | 与对应控件间距 |
| section.gap | 24px | 表单任务区块间距 |
| section.padding | 20–24px | 区块内边距 |
| section.border / radius | #E4E7EC / 8px | 白色区块边界 |

### 13.2 Tag统一主题

所有列表、详情、报告、模板和任务使用同一主题；标签采用12px字、20px行高、4px圆角、透明边框。普通业务类型为中性；颜色不表达精确数值，也不替代状态文案。

| 语义 | 文字 | 浅底色 |
| --- | --- | --- |
| 中性、未执行、不适用 | #526071 | #F3F4F6 |
| 运行中、信息、选中 | #1D4ED8 | #EFF6FF |
| 已发布、成功、通过 | #166534 | #F0FDF4 |
| 待处理、无法判定、警告 | #92400E | #FFFBEB |

| 辅助分类 | #6941C6 | #F4F3FF |

禁止深灰大底色和同一状态在不同页面使用不同颜色。

### 13.3 复杂表单

- 统一页面容器；标题操作栏与表单左右边界对齐。
- 区块按输入版本、处理方式、模型参数、可选自动质检、输出组织。每块一个清晰标题；同一块最多一级子分组，使用留白与细分隔，不用说明卡叠卡。
- 开关与所属区块标题同一行；关闭时收起依赖字段，保留草稿值且不阻止提交。
- 图像生成模型与图像理解模型严格区分。模型参数跟随对应模型，JSON校验不得接受无效配置。
- 新合成/增强/扩增任务自动质检默认关闭，由用户开启；旧配置按原行为回显。开启后只显示规则实际需要的语义、VLM或Embedding模型，函数检查不要求模型。
- 扩增按各目标独立配置数相加显示只读计划合计；不再设置“最大新增样本数”。规则不通过率独立列，分母=通过+不通过。

### 13.4 报告和隐私

报告按质检类型分区，各区保留搜索结果、通过率和六状态；提供通过率升/降序，缺少有效判定置后；“仅看异常规则”包括不通过、无法判定和未执行。默认展开主要质检类型，允许折叠。

隐私命中用表格表达：规则、命中次数、涉及样本数。次数与样本数不得互换；未知值显示未记录。涉及总样本数必须基于样本ID去重，不能直接加各规则数量。上传处理明细严格只呈现字段ID与触发规则，不呈现样本内容。

预期合成字段配置字段ID、隐私类型、允许区域/结构路径，来源要求固定为生成流程验证。三项匹配且有可信生成来源证据才豁免；缺少来源、上传数据、区域外泄漏仍检查。仅命名为“姓名”不构成豁免。历史报告缺少定位/来源证据时不能回填虚假豁免结果。

### 13.5 页面与任务行为

- 数据预览只展示数据与标注，规则结果统一进入质检报告。
- 配置快照放基础信息内的可展开区域，保留复制和完整内容。
- 失败/异常任务禁止编辑；重跑直接进入运行状态，保留原任务ID与历史运行证据，不进入编辑页面。
- 文档版面分析编辑使用独立页面，不显示“用户草稿”标签。
- 试运行按钮放对应配置底部右侧的操作区（上边距24px、内边距16px、细分隔），不得漂移至报告或无关区块。


### 13.6 数据缺失与验收反馈

- 历史字段ID或命中次数缺失使用“未记录”，不显示推算数字。
- 预期合成字段豁免必须由执行证据支持；配置本身不是来源证明。
- 快照及结果较大时使用持久存储；保存完成后刷新必须可恢复。保存失败应给出可理解的错误，不能显示虚假成功。
- 本轮实施与回归边界见《V5二轮回归记录-2026-09-16.md》。
