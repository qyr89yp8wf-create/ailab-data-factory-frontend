# V5 模板表单验收修订

## 修改与验收入口

| 项目 | 修改 | 验收方法 |
| --- | --- | --- |
| 1 输入控件 | 白底、浅灰边框；包含禁用、只读、数字后缀 | 任意模板输入框与模型参数区对比 |
| 2 普通提示 | 灰色 12px 单行，标题正文以分号衔接 | 对话生成空间、时序预览、文档试运行；长提示区域内横向滚动 |
| 3 添加按钮 | 列表标题行右侧蓝色加号按钮 | 维度、工具、返回类型、字段、场景规则、隐私豁免 |
| 4 时序第三步 | 删除编译状态、演示参数、估算、点数、字段数 Tag | 打开合成指令预览两个阶段 |
| 5 隐私豁免 | 移入隐私质检，改名，字段 ID 下拉解析 | 打开隐私质检，添加字段，下拉选择，不手输 ID |
| 6 规则类型计数 | 普通灰字（已选/候选） | 时序基础规则取消一项，17/17 变 16/17，再恢复 |
| 7 时序结果 | 移除曲线和 GPS；数据下载保留 | 试运行后查看结果与 CSV 下载入口 |
| 8 对话文案与格式 | 其它说明关闭态更新；新增维度有效；messages | 第一、二、五步分别核对 |
| 9 文档编辑器 | 白底按钮条、语义工具等宽、说明 info、对象列表在右侧 | 语义与字段规则步骤；文字列表拖动右下角调整高度 |
| 10 文档试运行 | 输出与模型配置分区，移除缩放 Tag，标注 JSON | 试运行后切换样例图/标注 JSON |
| 11 分类分布 | 无分类配置不显示卡片 | 无分类时序与文档试运行结果；有分类的对话保留卡片 |

## 已执行的验证

- 浏览器：文档结构/语义/质检/试运行步骤，白色操作条、右侧文字与图案列表、字段选择、标注页签。
- 浏览器：文档输入框计算样式为白色 `rgb(255,255,255)`、边框 `rgb(220,225,232)`；文字列表 resize 为 vertical。
- 浏览器：文档标注 JSON 长度约 298 KB，含画布、单元格、文字、图案与字段快照；无标签分类卡片。
- 浏览器：时序生成空间标题处新增维度、第三步清理、规则计数 17/17 → 16/17 → 17/17、试运行结果无曲线/GPS且保留 JSON 与 CSV 下载。
- 浏览器：对话其它说明关闭态、蓝色标题添加按钮、新增维度并移除测试行、隐私字段选项含 shipment_id/status 及 messages 数组路径、规则分类计数、messages 结果格式。
- 自动化：原 13 组回归通过；新增字段解析测试覆盖定义字段、JSON、JSONL、嵌套 JSON 字符串、去重、无效 JSON 和空定义项。
- 构建通过；V4 基线未改变，原 111 个文件保留。
- 走查发现的组件导入遗漏、计数函数作用域和表单空项问题已修复并重走对应页面。

## 原型边界

本轮不修改既有模型调用和任务生成逻辑。现有试运行仍为原型 Mock。文档新增的标注面板展示试运行时模板源坐标快照（明确标记 mock / coordinate_space），不声称是服务端模型实际生成的像素级真值；旧记录没有标注快照时使用模板数据预览。
