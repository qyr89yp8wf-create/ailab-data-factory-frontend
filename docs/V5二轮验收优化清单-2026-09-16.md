# V5 二轮验收优化清单

状态：已按用户确认实施；开发回归记录见《V5二轮回归记录-2026-09-16.md》。不将模拟质检当作真实模型验收。

## A. 全局视觉规范

- 所有页面逐项审查静态操作说明：默认灰色小字，无背景、无左边框、无装饰状态图标；长解释收到标题 info tooltip / popover。不能仅将彩色 Alert 改成灰色 Alert。
- 只有当前操作失败、阻断性错误和需要立即处理的问题使用明确状态反馈；隐私命中改为数据表，不作为大面积警告。
- 全局 Tag 使用统一浅色主题：中性灰、运行蓝、成功绿、异常红、待处理琥珀；低饱和背景，语义一致。记录具体颜色、字号、间距、边框于 Design Tokens。
- 复杂表单按输入、处理配置、可选质检、输出组织；以标题、留白和分隔建立层级，避免卡片内再层层套卡片。

## B. 信息组织与详情

- 上传任务隐私处理、校验失败增加明细，只允许字段 ID、触发规则；不展示样本内容或敏感原文。
- 数据预览移除“当前报告的逐规则结果”；质检结果统一进入质检报告。
- 质检任务移除 API 重试/Badcase 底部说明。
- 所有任务配置快照合并到基础信息的独立折叠区，保留完整内容及可访问性，不再单设页签；覆盖上传及三模态四种任务。
- 质检报告按基础、隐私、场景等真实类型分区，保留规则搜索、六种状态和样本明细。提供通过率升序/降序；无有效判定置后，不能视为0分。分区头展示规则数和异常概况，允许折叠。
- 隐私命中表：规则、命中次数、涉及样本数；合计样本数需去重。若历史报告不具备命中次数，显示未记录，不能用样本数冒充次数。

## C. 任务交互与配置

- 失败任务不可编辑，可直接重跑，不经过编辑页。按用户“直接状态变更”意图，在原任务上重新进入运行状态；需要保留可追溯的历史运行记录，不能丢失之前失败证据。
- 定向扩增将不通过率拆成独立列；明确分母为通过＋不通过，排除无法判定等状态。
- 建议数量现有公式：覆盖目标=max(目标覆盖数－当前数,0)；规则目标默认不通过数，可覆盖；选中目标合计＋自定义数量。旧版曾取该合计与“最大新增样本数”的较大值，命名与行为冲突；本轮已移除。
- 推荐改为目标独立配置数量，底部只读显示计划新增合计，移除最大数量字段。多规则命中同一样本不等于合计可以按样本去重：这是各目标的生成工作量。用户已确认并实施。
- 增强/扩增添加自动复检开关，合成添加自动质检开关。建议新任务默认关闭，历史任务按原配置回显。开关只控制后置质检，不隐式改变已有隐私处理策略。
- 检查阶段按规则需要选择语义模型/图像理解模型，函数规则不要求模型。用户已确认使用语义/VLM理解模型。
- 用户已确认指“图像生成模型”，已增加其JSON参数开关。文档图像适用图像生成模型及参数，不将对话/时序强制改为图像生成。

## D. 预期合成字段与隐私检查

建议模板增加预期合成字段配置：字段ID、隐私类型、允许出现的结构化字段/图像区域、生成来源证明。只豁免满足来源及位置约束的合成值；上传值不自动豁免、指定区域外泄漏仍检查。隐私处理与质检共用这一边界。判定层记录豁免对象，不显示敏感原文；现有模拟结果缺少可信定位/来源时保持不豁免。用户已确认并实现配置和判定边界，不能仅凭“姓名”字段名称排除全部检测。

## E. 模板编辑布局

- 开始试运行并质检按钮与对应配置同区，在试运行步骤底部操作区统一放置；避免遮挡和跨区漂移。
- 文档版面分析法编辑改为独立页面，保留返回路径，移除“用户草稿”标签。
- 新建文档图像模板第一步表单与上方按钮栏使用同一宽度容器。

## 验收要求

全局检查首页、数据中心、上传详情、版本详情/预览/报告、三类任务创建与详情、三类模板新建/编辑/试运行及API设置。分别验证视觉、配置保存/回显、任务提交、状态变化和报告数据口径。更新UED Design Tokens的提示、状态Tag、复杂表单、表格及操作栏规范。新增业务行为需补充测试，不将上一轮测试结果当成本轮通过。


## 本轮附带修复

- 闭环验收发现 localStorage 容量耗尽导致刷新后任务丢失。任务/报告/数据集状态改用 IndexedDB；旧存储成功迁移后才缩减为元数据，保留既有记录。
- 文档模板编辑自动保存后曾因丢失编辑标记转为只读，已修复标记保留。
- 失败任务缺少可恢复模板配置时给出明确说明，不再跳入编辑页。完整配置任务直接重跑，运行日志保留 previous_runs。

## 实现边界

- 本地任务质检和上传校验原本采用模拟执行；没有把本轮UI验收说成真实模型准确率验收。
- 旧上传记录没有字段ID时显示“未记录字段 ID”；新模拟记录可使用模板声明字段ID。不会根据敏感原文推断并回填历史记录。
- 隐私豁免已实现字段、区域、来源联合判断和边界测试。现有模拟对象没有可信来源元数据时不会豁免；真实生成/检测服务接入时必须提供验证后的来源和区域证据。
