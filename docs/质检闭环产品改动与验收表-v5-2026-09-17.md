# v5 质检闭环：产品改动与验收表

原型目录：`Data_Factory_User_Frontend_v5`。本地预览：`http://127.0.0.1:8769`。

## 1. 建议验收顺序

先模板规则与标签 → 试运行 → 上传发布处置 → 质检报告 → 定向扩增 → 输出版本。

|序号|改动点|入口与操作|验收标准|
|---|---|---|---|
|1|三类模板统一规则目录|模板中心分别编辑文档、对话、时序模板，进入质检步骤|公共隐私、安全、文本基础质量一致；各模态分类及编号按02正文，不显示附录规则|
|2|配置类型区分|分别打开固定规则、参数化规则、自定义规则|固定规则只读；参数规则只开放对象及规定参数；自定义规则可填写名称、对象、条件/Prompt|
|3|参数保存与取消|修改金额小数位、字符长度或时间容差；分别取消、保存后重开|取消不生效；保存回显；数值类型及上下界不合法时拦截|
|4|自定义规则实例|添加两条自定义规则，关闭或删除其中一条；保存模板|各自ID不同；关闭或删除的实例不进入后续执行快照|
|5|字段关联质检|文档/时序模板已有逐字段检查条件，进入质检页|显示对应字段规则实例，报告独立定位字段；不只展示一个泛化规则占位|
|6|文档自定义标签|文档模板点击“添加自定义标签”，填写枚举及Prompt|可添加、编辑、启停；空Prompt、重复枚举不允许保存；文档不增加系统事件自动打标|
|7|事件自动分类与自定义分类|对话/时序先配置事件采样维度，再进入质检步骤|自动继承维度及枚举；系统自动规则不能改成用户标签；另可新增自定义标签|
|8|模板试运行|保存规则/标签后试运行，查看逐规则报告|报告包含启用规则及标签分布；标签不参与整体质量分；后续修改配置会使旧试运行失效|
|9|质检任务配置|三类任务中心新建数据质检|选择版本、检查范围、所需模型；不再选择规则/字段/通过阈值；提交冻结模板配置|
|10|报告统一|打开数据集版本、质检任务、增强任务、扩增任务的同一报告|编号、条件、分数、计数、标签一致；内置旧演示报告有新版结果；用户历史快照不被重算|
|11|分数与说明|报告查看整体分数、有效判定覆盖率、隐私不通过；悬停info图标|三个指标同排中性样式；无法判定不当失败；无有效结果不伪装100%；公式可查|
|12|标签覆盖与分布|报告底部切换自动/自定义标签、切换维度|显示覆盖率、覆盖标签数、已分类/无法分类、数量与占比；0样本标签保留；抽检不外推全量|
|13|样本下钻|点击规则失败数量、标签数量|分页显示对应样本ID；失败项有位置/原因；标签分类与质量结论分开|
|14|上传命中报告|上传对应示例包，保存后点发布|强制文件、隐私、安全检查；有命中进入待处理；列出样本ID/规则/类别；未经选择不自动脱敏|
|15|上传三种处置|在命中报告选择删除命中、返回编辑或配置脱敏|删除按样本去重；返回编辑保留历史；只有隐私命中可脱敏；安全/文件/检测异常不能借脱敏绕过|
|16|上传边界|全样本命中、文件错误、检测异常、重复发布、停止后重发|不能发布空集；异常阻断；不重复启动；多次检查历史可回看，发布后数量同步|
|17|标签定向扩增|新建定向扩增，选版本及报告，查看标签目标；改每标签目标数|默认补齐本维度最多标签；80/20/0推荐0/60/80；目标50时为0/30/50|
|18|规则失败定向扩增|切到“规则不通过”，点击规则名、选目标并改数量|能看失败样本；仅FAIL计推荐量，不把ERROR或隐私安全命中作为扩增目标|
|19|计划合计与联合目标|手改计划数、取消选中、换版本/报告，添加自定义联合目标|只合计选中项；换来源清空旧目标；联合目标数量手填，不从边际分布伪造交集；零/小数不提交|
|20|扩增产物与快照|提交2条扩增；任务完成后查看配置快照及输出版本|目标和计划数保留；新版本2条、新sampleId；原版本不变；规则扩增有失败父样本引用|
|21|自动复检开关|扩增分别关闭/开启自动质检|关闭不伪造新报告；开启按冻结规则及标签生成结果；增强选样不出现按失败规则筛选入口|
|22|仅增强规则|普通文档与增强文档报告对照D13|普通样本为不适用；增强样本有执行结果；全不适用规则不拉低整体分数|
|23|持久化与布局|保存后刷新，1280px检查表格、弹窗、报告|配置和任务保留；整页不横向溢出；大表局部滚动；查看模式不允许保存修改|

## 3. 本轮验证范围

- `npm test`：14个测试脚本通过，其中新增质检闭环32项用例；覆盖95项目录与02的一致性、三模态快照/报告、上传状态机及异常、扩增计算与父样本、缓存演示迁移幂等。
- `npm run build`：通过；仍有原工程的大体积打包提示，不阻断运行。
- 浏览器逐项走查代表路径：三模态规则页、发布模板只读、自定义标签保存回显、试运行与下钻、上传发布和手动脱敏、扩增推荐量修改与实际提交、输出版本2条、三模态报告及增强报告覆盖分布、1280px布局。
- 文件错误、全命中、混合安全、停止/重复操作等分支由状态机自动化用例覆盖；未将这些称为全部浏览器分支实测。

测试发现的异常及处理见《质检闭环测试异常报告-v5-2026-09-17.md》。
