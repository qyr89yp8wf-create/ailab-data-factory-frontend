## 2. 设计依据与落地结果

设计依据：本目录的 `UED审查与优化建议-2026-09-16.md` 和 `UED设计与Design-Tokens-2026-09-16.md`。

| 原问题 | V5 实现 | 功能保留方式 |
| --- | --- | --- |
| 数据集、版本、任务详情抽屉连续叠加 | 改为主内容区全宽详情工作区，使用返回按钮逐层返回 | 保持原详情内容、数据与回调；下层页面保留状态，仅当前导航页面可交互 |
| 规则样本继续叠加抽屉 | 数据集和版本不再占用抽屉，仅样本明细保留一层抽屉 | 状态筛选、样本展开、计分和分页沿用原逻辑 |
| 长表单分组混乱、姓名描述悬浮遮挡 | 任务名称与描述回归正常文档流；标题与提交操作固定在顶部 | 所有原表单字段、校验和参数开关保留 |
| 右栏报告过窄、双栏滚动互相干扰 | 同页分成“任务配置”和“任务依据 · 模板与质检报告”两页签 | 完整依据内容移到页签内，不裁掉规则或报告；切换保留配置 |
| 大面积彩色说明争抢注意力 | 普通说明使用中性色、轻分隔线；错误与必要警示保留状态色 | 说明文字继续可见，不删除业务条件 |
| 字号、间距、色彩、表格不一致 | CSS variables 与 Ant Design theme 统一管理 | 不改变数据列、计算口径和状态含义 |
| 模板只读字段对比度低、文档画布失去上下文 | 只读文本提高对比度，文档画布在宽屏保持可见 | 只读权限和字段内容不变 |
| 长弹窗标题、底部按钮滚出视野 | 弹窗正文内部滚动，标题和操作固定；消除表单负边距导致的横向溢出 | 原字段和保存操作全部保留 |
| 对话模板展开规则可能白屏 | 对空规则记录添加渲染保护 | 仅防止读取空记录的 rule_id，不修改规则定义 |

详情工作区使用现有组件状态导航，不宣称新增浏览器历史路由。设计建议中的新增业务能力未纳入本次实现；本次范围为现有页面的视觉和交互重构。
