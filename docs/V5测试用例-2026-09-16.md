# V5 详细浏览器测试用例

## 测试约定

- 目标：`http://127.0.0.1:8769/`，V5 用户端；2026-09-16。
- 方法：按下表逐条通过浏览器操作；结果另记于《V5测试执行记录-2026-09-16.md》，缺陷另记于《V5测试不通过项目-2026-09-16.md》。此前回归结果不直接算作本轮通过。
- 默认前置：服务运行、首页可访问、保留内置示例；每条用例从指定入口开始。测试新建数据使用 `QA-V5-0916` 前缀。
- 状态：通过＝本条步骤和可观察断言完成；失败＝实际与预期不符；阻塞＝无法取得必需环境或授权；未执行＝尚未操作。测试工具定位失败先重新观察，不直接登记产品缺陷。
- P1：核心流程或数据正确性；P2：一般交互/校验；P3：轻微视觉问题。
- 对照依据：V5 交付记录、UED/token 文档，以及现有页面文案。旧 QA 文档存在质检版本策略冲突，业务口径以较新的《质检改造验收清单》为参考，冲突单独标明。
- 不改产品源码；不执行永久删除、不保存真实密钥、不连接真实模型。此类最终动作列为阻塞，不计为通过。
