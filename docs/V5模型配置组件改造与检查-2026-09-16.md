# V5 模型配置组件改造与检查

## 改动

- 新增 ModelConfigField / ModelConfigGroup，FormModelConfig 和 ControlledModelConfig 适配现有两种状态管理方式。
- 选择框与参数同区，无参数卡片嵌套、无重复参数标题；说明进入info，错误在编辑器下方。
- 保留模型ID、默认值、选项限制、开关存储字段和原提交函数；不添加真实模型调用。

## 浏览器检查

- 三模态×四类任务的12个创建入口逐页打开/返回：可达；未选择数据前依赖模型按原逻辑不显示。三个合成入口可看到统一组件。
- 文档模板新建（用户截图路径）：模型名称简化；默认参数关闭，开启即出现同区JSON；截图确认无额外卡片边框。
- 文档新建参数填写 `{"temperature":0.3}` → 关闭 → 重开：值保留。
- 文档新建参数填 `[]`：显示JSON对象校验错误；改回对象错误消失。
- 对话已发布模板→试运行：生成/质检模型均使用新组件，选择和开关继续禁用。
- 时序已发布模板→试运行：生成/质检模型均使用新组件，只读状态保留。
- 文档版面分析模板→校验试运行：字段生成、语义质检、VLM三组纵向配对，原调用次数预估保留。

浏览器检查验证代表路径与组件交互，旧MVP等分支以源码覆盖和构建验证为主；未重新执行真实模型请求或穷举每个模板。
